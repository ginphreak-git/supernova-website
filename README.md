# Super Nova IPTV – sito web

Sito informativo e informativa sulla privacy di **Super Nova IPTV**, pubblicati con GitHub Pages.

- `index.html` (italiano), `en.html`, `es.html`, `fr.html`, `de.html` – presentazione nelle 5 lingue.
  La pagina principale apre da sola la lingua del browser e ricorda quella scelta dal selettore.
- `privacy.html` – informativa sulla privacy in 5 lingue (`#it`, `#en`, `#es`, `#fr`, `#de`)

Sito statico: nessun framework, nessun tracciamento.
